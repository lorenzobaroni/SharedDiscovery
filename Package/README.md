# SharedDiscovery

SharedDiscovery shares item/material discoveries with everyone in the same Valheim world.

When a player discovers an item, the server records that stable prefab ID for the world and synchronizes it to other players. Clients apply the discovery through Valheim's native discovery flow, so vanilla recipe logic and vanilla notifications remain in charge.

Server and clients should install the same mod version.

SharedDiscovery does not force recipes.
